# Procore Integration

This project contains the initial setup for a FastAPI-based Procore integration.

Completed work:

- FastAPI project setup
- Webhook endpoint structure added
- PostgreSQL database schema (`schema.sql`) created
- Project and submittal API endpoints added
- Basic analytics endpoint implementation
- Environment configuration support using `.env`

Project structure:

procore-integration/
 app.py
 schema.sql
 requirements.txt
.env.example
 README.md

Current status:

The complete Procore integration and live webhook synchronization could not be fully completed during implementation. The repository currently contains the application structure, API logic, and database schema setup.

Note:

`schema.sql` is available in the project root as required.
